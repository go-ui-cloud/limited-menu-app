# 期間限定グルメ V1.3

V1.3 の変更点:
- 取得済み商品をブラウザの localStorage に14日間保存
- 再取得で同じ商品を確認できた場合は内容を更新し、保存期限を14日延長
- 新商品は追加
- 今回取得できなかった商品も、最後に確認できた日から14日以内なら表示を維持
- 21店舗を1回のAPI処理にまとめず、フロント側から店舗単位で取得（同時3店舗）
- 1店舗の失敗で全店舗が0件になるのを防止
- 6時間以上最終確認していない場合はページ表示時に自動確認
- 手動の「最新情報に更新」で即時再確認
- 更新結果に「取得成功 / 商品なし / エラー」の件数を表示

## 注意
保存は各ブラウザの localStorage です。同じURLでも別ブラウザ・別端末には共有されません。
