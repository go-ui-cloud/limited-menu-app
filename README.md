# 期間限定グルメ V1.6

V1.6では、公式サイト・公式X（旧Twitter）・ニュース記事を組み合わせて期間限定商品を探します。

## V1.6の主な変更点

- 公式Xの投稿も情報源として利用
- Xは店舗ごとの公式アカウントに一致する `/status/` 投稿だけを採用
- Xの検索結果はBing RSSのインデックス情報を利用し、X本体が取得できない場合でも候補を判定
- 公式Xは「商品を示す語」＋「期間限定/終了期限」または「発売日付きの発売・販売開始」を確認できる場合に採用
- プレゼント、フォロー&リポスト、抽選などキャンペーンだけの投稿は除外
- 公式サイトを最優先し、公式Xを補助、その後にニュースサイトを利用
- Wikipedia、通常メニュー、店舗情報、まとめ記事は引き続き除外
- 取得済みの確認済み商品はPostgres/Neonに14日間保存
- 価格・画像・終了日など確認できない項目は推測しない

## 注意

Xの公開ページや検索エンジンのインデックス状況により、すべての公式投稿を必ず取得できるわけではありません。取得できない場合は公式サイトやニュース記事へフォールバックします。公式Xアカウントを確認できない店舗は、誤取得を避けるためX情報を無理に採用しません。

既存のNeonデータベースと `POSTGRES_URL` / `DATABASE_URL` はそのまま利用できます。
