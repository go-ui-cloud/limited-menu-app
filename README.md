# 期間限定グルメ V1.5

V1.5では「期間限定である根拠が確認できた商品だけ」をDBに保存・表示します。

## V1.5の主な変更点

- 「新商品」「新発売」だけでは期間限定と判定しない
- 以下のような明確な根拠を点数化して採用
  - 期間限定
  - 季節限定
  - 数量限定
  - 限定販売
  - なくなり次第終了
  - 販売期間 / 提供期間
  - 明示された販売終了日
- ニュースサイトはタイトルまたは概要に期間限定の直接的な根拠がある記事を優先
- Wikipedia、X/Twitter、Instagram、Facebook、TikTok、YouTube等を商品ソースから除外
- 通常メニュー、店舗一覧、検索結果、まとめ/完全ガイド/ランキング系ページを除外
- 取得商品に `verified_limited=true`、根拠文、判定スコアをDB保存
- V1.4以前の既存DB行は未確認扱いになり、V1.5では表示されない
- V1.5で再取得・確認できた商品だけ一覧に復帰
- 確認済み商品は従来どおり最終確認日から14日間DB保存
- 1店舗の取得失敗で全店舗の更新が止まらない仕様は継続

## データベース

Neon/Postgresを利用します。Vercel側に `DATABASE_URL` または `POSTGRES_URL` が必要です。
V1.4のDBをそのまま利用できます。初回アクセス時に必要な列を自動追加するため、手動SQLは不要です。

追加される列:

- `limited_evidence`
- `evidence_score`
- `verified_limited`

## 注意

V1.5は誤検出を減らすため、V1.4より厳しい判定です。そのため、実際には期間限定でも引用元ページ上で根拠を十分に確認できない商品は表示されない場合があります。不明なものを推測して掲載することはしません。
